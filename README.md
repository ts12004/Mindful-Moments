🌿 Daily Mindful Moments

A wellness dashboard with daily affirmations, mood tracking, and breathing exercises. Built with PHP, CSS, and HTML.

✨ Features

Daily Affirmations - Random positive quotes that refresh on click
Mood Tracker- Log your mood with 5 different options
Mood Journal - View history with timestamps
Mood Statistics - See your mood patterns
Breathing Exercise- Pure CSS animated breathing circle
Persistent Storage - All moods saved to text file


🛠️ Technologies Used

- PHP (Backend logic & file storage)
- HTML5 (Structure)
- CSS3 (Styling & animations)
